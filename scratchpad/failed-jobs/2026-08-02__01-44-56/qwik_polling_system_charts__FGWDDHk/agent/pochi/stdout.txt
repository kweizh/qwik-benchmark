# Qwik Polling System with Dynamic SVG Charts ## Background Build a self-contained polling system using Qwik and Qwik City. The application will fetch poll questions and options from a local SQLite database, display them to the user, render a dynamic SVG-based bar chart of the results, and allow users to cast votes.
